# THE BOYZ ARCHIVE

Main navigation page for the fan-made THE BOYZ media archive.

## GitHub Pages

1. Upload all files from this repository to the `main` branch.
2. Open **Settings → Pages** in the GitHub repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.

The site uses only static HTML, CSS and JavaScript, so it does not require a build step or API keys.

## Editing the FAQ

Questions and answers can be added directly in `faq.html`. Duplicate the existing `.content-row` article for each new entry.
